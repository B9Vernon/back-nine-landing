# Back Nine Tournament Portal — Field Map

Admin portal (Vernon-supplied): https://franchise.backninegolf.ca/app/#/tournaments/view/7
(SPA behind login — usable only through an approved browser session in FILL B9 PORTAL mode.)

## Portal fields (event entry form)

poster · title · event type · status · total bookings · members-only setting ·
registration deadline · event dates · bays · participant limit · maximum booking
length · start hour · end hour · member entry fee · non-member entry fee · Full Swing
event code · **Tournament Details (accepts HTML)** · public event URL.

## Public event page displays

event poster · event title · Full Swing information · dates · event type · hours ·
participant count · entry fee · **the custom HTML description** · registration links
and buttons.

Because the portal already displays poster/title/dates/fees natively, the Tournament
Details HTML should not merely duplicate those fields — it repeats key facts inside the
sales flow (Important Event Information section) but its job is persuasion, structure,
and CTAs.

## FILL B9 PORTAL protocol

Only when Vernon explicitly issues the command AND an approved browser/computer-use
connection exists:

1. Open the Back Nine tournament portal.
2. Locate the correct event or new-event page.
3. Fill ONLY the fields Vernon has approved.
4. Paste the approved HTML into Tournament Details.
5. Upload the approved poster when available.
6. Verify every entered value against the approved Build Pack.
7. **STOP before clicking any final Save, Publish, Update, or Submit button.**
   Vernon approves or performs the final action. No exceptions.

## Learning the portal

Screenshots Vernon uploads and previous event HTML are technical guidance and
inspiration only — understand the mechanics from them, never copy them blindly. Record
any portal HTML quirks discovered (stripped tags, style limits, width behaviour) in
`../memory/event-log.md` under Portal HTML Issues.
