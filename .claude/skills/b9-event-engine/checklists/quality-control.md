# Quality Control — run silently before delivering any build

Repair every failed item before delivery. Never deliver with a known failure.

## Concept

- [ ] Concept is original (checked against `../memory/event-log.md`)
- [ ] Suits Vernon's current or upcoming season
- [ ] Professional-golf information is current (researched at build time, when used)
- [ ] No false affiliation implied; no protected names/logos/likenesses used

## Copy

- [ ] Description is persuasive (passes the stop/read/click/pay/compete test)
- [ ] All 11 required sections present, in order
- [ ] Prize section accurate — nothing invented, no "everyone wins" implication
- [ ] No unsupported handicap claims; no unsupported algorithm/exposure claims
- [ ] Golf Canada section is app-first, exact facility name used

## Facts & links

- [ ] All supplied dates match everywhere they appear
- [ ] All supplied fees match everywhere they appear
- [ ] All supplied links match; zero guessed URLs
- [ ] No user-controlled field was invented — placeholders used instead
- [ ] Every `{{placeholder}}` appears in the Image or Link Replacement List

## HTML

- [ ] Complete, contiguous, copy-paste ready fragment (no doctype/html/head/body)
- [ ] Inline CSS only; zero JavaScript
- [ ] CTA buttons present, high-contrast, thumb-sized
- [ ] Three-step signup flow clear and numbered
- [ ] Membership CTA present but secondary
- [ ] Images/logos present or clearly labelled placeholders; all have alt text
- [ ] Mobile presentation strong (stacking, max-width:100% images, big tap targets)
- [ ] Visually engaging — NOT mostly plain white
- [ ] Final registration CTA is the most prominent element near the end

## Conduct

- [ ] Nothing was published, saved, or scheduled automatically
- [ ] Any recommended connection is specific (what/why/access level/required-or-optional)
- [ ] No unnecessary access requested
