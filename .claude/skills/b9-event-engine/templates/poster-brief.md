# Poster / Hero Image Brief — template

Fill every section. Deliver alongside the Build Pack when direct image generation is
unavailable; otherwise generate the asset and include export specs only.

## 1. Asset

- Primary: portal poster — **1080×1350 px (4:5)**, PNG or JPG ≥ 80% quality
- Optional variants: 1080×1080 social square · 1080×1920 story
- Must stay readable at ~300px wide (portal thumbnail test)

## 2. Design brief

One paragraph: event mood, theme, competitive feeling, seasonal cue.

## 3. Visual hierarchy (top priority first)

1. Event name (largest)
2. One-line hook or format line
3. Dates ({{EVENT_DATES}})
4. Back Nine Vernon branding (logo, exact proportions)
5. Prize message (when appropriate)
6. Supporting imagery

## 4. Text placement

Specify zones (e.g. name upper third, dates band lower quarter, logo bottom-right).
Keep all text inside a 5% safe margin.

## 5. Colour instructions

Base: deep navy `#10171F` / page dark `#07090D`. Signature accent: Back Nine green
`#96CB39`. Premium/prize accents: gold `#D4AF57`. Secondary: blue `#39B8DE`. Seasonal
accents layered, never neon-flooded. Premium, dark, modern — never cheap, cluttered,
arcade-like, or game-engine looking.

## 6. Asset list

Which approved logos/photos to use and where they come from (public HTTPS URL or
Vernon-supplied file). Never protected pro-golf imagery, marks, or player likenesses.

## 7. Crop instructions

Focal point, what may be cropped per variant, what must never be cut (logo, event name,
dates).

## 8. Image-generation prompt

A complete, ready-to-run prompt (photorealistic premium indoor golf; simulator bay;
dark modern architecture; controlled lighting; **at most one golf ball visible**; no
text — text is applied in layout, not generated).

## 9. Export specifications

Format, quality, colour profile (sRGB), file naming
(`b9-{event-slug}-poster-1080x1350.png`), and the public HTTPS hosting note for portal
use.
