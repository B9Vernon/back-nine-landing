## Source health

URLs drift. If a source 404s or restructures, find its current location via
search, use it, and update this file in the same run. If a source is
paywalled or blocked, skip it — never bypass. Note dead/weak sources at the
bottom of `state/opportunity-log.md` so future runs don't waste time.
