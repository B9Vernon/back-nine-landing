# MONITORING SCHEDULE (honest capability statement)
Manual activation only, by design (investor preference, set 2026-07-10). No Routine, cron,
or scheduled trigger runs this system automatically — nothing fires on its own. All reviews
(daily/weekly/monthly/quarterly/annual workflows in 00_CONTROL_CENTER/COMMANDS.md) exist as
commands and run only when you invoke them in a session.
On every activation: health → freshness → alerts → thesis-breakers → distribution changes →
portfolio risks → ACT re-qualification → duplicate suppression.
If you later want recurring automatic runs, a platform Routine can be created on request —
none is active now.
