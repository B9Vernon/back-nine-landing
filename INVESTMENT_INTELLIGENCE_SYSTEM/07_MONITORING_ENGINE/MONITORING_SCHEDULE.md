# MONITORING SCHEDULE (honest capability statement)
Real background monitoring: a platform Routine is scheduled to fire "RUN WEEKLY REVIEW"
weekly (Mondays 13:00 UTC) into the system session. Between firings, NOTHING runs — there is
no intraday or daily automated scan. Daily-scan and monthly/quarterly review workflows exist
as commands and run when invoked (manually or by adding further Routines).
On every activation: health → freshness → alerts → thesis-breakers → distribution changes →
portfolio risks → ACT re-qualification → duplicate suppression.
