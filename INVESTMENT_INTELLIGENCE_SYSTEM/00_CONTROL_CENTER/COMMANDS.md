# COMMAND REFERENCE
Say any of these in a session; the system executes the mapped workflow (09_MODULES/MODULE_LIBRARY.md).

RUN FULL SYSTEM            — full 25-step execution order (see master mandate §34)
RUN CURRENT MONITOR        — health, freshness, alerts, thesis-breakers, material changes
RUN WEEKLY REVIEW          — holdings, watchlist, revisions, valuations, new opportunities
RUN MONTHLY PORTFOLIO REVIEW — overlap, distribution quality, NAV trends, concentration
RUN WORLD OUTLOOK          — refresh Top-10 research panel + theme ranking
ANALYZE MY PORTFOLIO / UPDATE MY PORTFOLIO
SHOW ACT | SHOW WATCH | SHOW AVOID | SHOW ALERTS
DEEP DIVE [TICKER] | SCAN [TREND] | COMPARE [A] VS [B]
CHECK DIVIDEND [T] | CHECK DISTRIBUTION [T] | CHECK VALUATION [T] | CHECK THESIS [T]
SHOW THE FULL RESEARCH | SHOW THE DIVIDEND ANALYSIS | SHOW THE PORTFOLIO OVERLAP
SHOW THE RED-TEAM CASE | SHOW THE THESIS-BREAKERS | SHOW THE TAX CONSIDERATIONS | SHOW THE STRESS TEST
EXPLAIN WHY THIS PASSED | EXPLAIN WHY THIS FAILED
GIVE ME 10 NON-OBVIOUS NAMES | DEEP DIVE THIS TREND | FIND REPLACEMENTS FOR [TICKER]
WHAT CHANGED SINCE LAST RUN?

Rules: outputs stay short (ACT max 3, WATCH max 5, AVOID max 3, RISK max 3).
Deep-dive commands expand only the requested area.
