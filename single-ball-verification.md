# Single-Golf-Ball Verification (run before EVERY golf output)

Confirm each item before returning any golf-related prompt, image sheet, or sequence. If any
answer is "no" or "uncertain," fix the prompt (simplify, split the clip, or move the ball out of
frame) before shipping. Full rules: `references/single-golf-ball-protocol.md`.

- [ ] Is the single golf ball clearly identified as one continuous physical object?
- [ ] Is its starting position explicit in every clip where it appears?
- [ ] Is its movement physically believable (speed, spin, trajectory, contact)?
- [ ] Is its final position clear in every clip?
- [ ] Across connected clips, does the ball's end position match the next clip's opening position?
- [ ] At impact, does the ball leave its original position and continue as the same object (no ball
      left behind on the turf)?
- [ ] Is there NO moment where the ball appears both at address and in flight?
- [ ] Could any **reflection** (glass, metal, screen, ball gloss) look like a second ball? Blocked?
- [ ] Could any **motion trail / blur** look like a second ball? Forced to abstract light/air?
- [ ] Could any **screen graphic / HUD / ball-tracking** read as a physical ball? Forced to
      abstract line/arc/dot?
- [ ] Could any **prop, basket, logo, or background** contain an extra ball? Blocked?
- [ ] Could any **transition** between clips spawn a duplicate ball? Transition changed if so?
- [ ] Is the SINGLE-GOLF-BALL LOCK section present in the prompt?
- [ ] Do the NEGATIVE LOCKS explicitly forbid any second/extra/ghost/duplicated ball anywhere?

**Final gate:** THERE IS ONLY ONE GOLF BALL — and never more than one.
